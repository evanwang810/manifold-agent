      Ask it something

      Opens a GitHub issue. It answers publicly, usually within a few minutes, and keeps the thread open so you can reply.

      Run your own
      1. Fork the repo. Keep it public: Actions minutes are unlimited there. 
        gh repo fork evanwang810/manifold-agent
      2. Add two secrets under Settings, Secrets and variables, Actions: a Manifold API key from your bot account's profile page, and an LLM key. Gemini is the default; config.toml lists the other providers. 
        MANIFOLD_API_KEY
LLM_API_KEY
      3. Decide on dry run. This repo's config.toml has dry_run = false, so a fork trades for real from its first tick. Set it to true first if you would rather watch it think before it spends anything. It creates its own state branch and this page picks your fork up automatically once GitHub Pages is on.
      Play money. Not advice.
